## Environment Variables

Semua variabel dideklarasikan di `.env.example`. Jangan pernah commit `.env`.

| Variable | Required | Description |
|---|---|---|
| `NODE_ENV` | Yes | `development` atau `production` |
| `PORT` | No | Server port (default: 3000) |
| `DATABASE_URL` | Yes | Connection string PostgreSQL 15 |
| `PUBLIC_FE_ORIGIN` | Yes | Origin user FE untuk allow-list CORS `/api/public/*` |
| `ADMIN_FE_ORIGIN` | Yes | Origin admin FE untuk allow-list CORS `/api/admin/*` |
| `ADMIN_JWT_SECRET` | Yes | Secret untuk verifikasi sesi admin (via GKE Secret) |

> Zone 1: bagian "External API Variables" & "External Dependencies" harus kosong. Jika terisi, eskalasi ke squad lead.

## Local Development Setup

### Prerequisites
- Docker Desktop
- Node.js 22 LTS (`nvm use`)
- pnpm atau npm

### Run locally
```bash
cp .env.example .env      # isi nilainya
docker-compose up --build
# App: http://localhost:3000   Postgres: localhost:5432
```

### Run tanpa Docker
```bash
npm install
cd apps/backend && npm run dev      # Terminal 1
cd apps/frontend && npm run dev     # Terminal 2 (Vite dev, proxy /api → :3000)
```

## Architecture Notes

Backend adalah satu-satunya sumber data untuk seluruh sistem Bliblitalk. Ia expose dua permukaan:
`/api/public/*` (dikonsumsi `bliblitalk-user-fe` lewat internet, CORS allow-list + rate limit) dan
`/api/admin/*` (dikonsumsi admin FE, auth admin wajib). Perubahan bentuk response public wajib
lewat versi (`/api/public/v1/...`) agar tidak diam-diam merusak repo user FE.

```
## Agentic AI Champion — Vibe Coding Rules (bliblitalk-admin)

Ikuti aturan ini kecuali diinstruksikan lain.

### Tech Radar — Always On

### Stack Rules
- Frontend: React 19 + Vite + TypeScript. No CRA, Next.js, Vue, Angular, Nuxt.
- Styling: Tailwind utility-first → shadcn/ui → Blu tokens (layer terluar).
- Backend: Express.js + Node 22 LTS + TypeScript. Route di apps/backend/src/routes/.
  Pisahkan routes/public/ dan routes/admin/.
- Database: PostgreSQL 15 only (pg atau Prisma Migrate). No SQLite/in-memory.
- Logging: Pino. No console.log di production path.
- Validation: Zod untuk semua request/response.
- HTTP client-side: window.fetch. No axios.
- Dates: dayjs. No moment.js.
- Testing: Vitest (unit) + Playwright (e2e). No Jest.
- Package manager: pnpm/npm. No Yarn.

### File & Structure Rules
- Frontend code → apps/frontend/ ONLY
- Backend code → apps/backend/ ONLY
- Shared interfaces/DTOs/enums → packages/shared-types/ (import @repo/shared-types, jangan salin)
- Shared utils → packages/shared-utils/
- apps/frontend/src/: app/ features/ components/ hooks/ services/ store/ layouts/ pages/ utils/ types/
- services/ = API calls ONLY (window.fetch). pages/ tipis. Business logic di features/.
- Functional components only. Component max 300 baris.

### API Boundary Rules
- /api/public/* dikonsumsi repo user FE. JANGAN ubah bentuk response tanpa versi baru (/v1).
- /api/admin/* wajib auth admin.
- CORS per-prefix pakai allow-list origin (PUBLIC_FE_ORIGIN / ADMIN_FE_ORIGIN). Bukan wildcard.
- /api/public/* wajib rate limit.

### Code Quality
- Lolos ESLint + Prettier. TypeScript strict, no `any` tanpa komentar.
- async/await, bukan Promise chain. Catch error di tiap route, return JSON error terstruktur.

### Env & Secrets
- Semua env di .env.example dengan komentar. .env di .gitignore.
- Jangan hardcode secret. process.env.* selalu. Secret produksi via GKE Secrets.

### Zone 1 — No External API Calls
Project ini Zone 1. JANGAN tambah panggilan ke API eksternal, LLM, atau layanan pihak ketiga.
Semua data tetap di jaringan internal. Tandai dependency eksternal apa pun sebagai blocker.
```
